# Sample Residence Visa Application Form

A standalone, self-contained HTML form for demos and testing (GovFill). It is not a government portal and submits nothing: entered data stays in the browser.

Live page: https://3sdeveloper.github.io/visa_form/

## Pages

- `index.html`: residence visa application (5 steps, validation, file uploads).
- `secure-form.html`: visa amendment request with a one-time password (always `123456`) and a human check that completes automatically. Request fields change with the request type.
